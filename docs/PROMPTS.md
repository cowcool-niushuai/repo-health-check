# Vibe Coding 提示词与开发过程记录

1. **项目架构初始化**：
   - 需求：按防失忆文档结构搭建 FastAPI + 可视化单页前端的 Git 仓库接入体检工具，支持公开 GitHub 仓库浅克隆、四大维度扫描、可解释评分与 AI 建议。
2. **扫描器与脱敏校准**：
   - 需求：用真实开源仓库（`pallets/flask`、`psf/requests`）测试后发现测试夹具证书、Sphinx `docs/make.bat`、代码注释与相对路径被误报，要求按目录上下文与同目录替代脚本进行分级降噪，并对密钥片段强制脱敏。
3. **可视化与交互体验优化**：
   - 需求：采用简洁亮色扁平排版（去掉卡片套卡片），使用 Apache ECharts 仪表盘与四维度雷达图展示评分；支持页面内可选配置 AI 模型参数、关键词搜索风险、维度联动筛选与一键导出 Markdown 报告。
