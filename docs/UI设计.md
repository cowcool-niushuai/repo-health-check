# UI 设计

## 页面布局（单页应用，简洁直观）
1. **顶部 Hero 输入区**：
   - 标题 + 副标题说明
   - 仓库 URL 输入框 + 「开始体检」按钮（支持 Loading 状态提示）
   - 2~3 个「示例仓库」快捷标签按钮，点击即填入并扫描
2. **总览仪表盘（扫描完成后展示）**：
   - **左侧**：接入就绪度总分环形图（0-100）+ 等级徽章（A/B/C/D）+ 所基于的 Commit SHA 与分支标签
   - **右侧**：四维度雷达图 / 柱状对比图（工程完整度、跨平台兼容、路径可移植性、密钥安全）
3. **AI 接入建议卡片**：
   - 项目定位一句话总结 + 推荐启动方式 + Top 3 整改建议 + 标明生成来源（AI 模型 / 规则引擎）
4. **工程完整度明细卡片**：
   - README、依赖清单、启动脚本三项状态徽章与命中文件列表
5. **主要风险清单**：
   - 支持按严重程度（全部 / 高危 / 中危 / 低危）与类别筛选
   - 每条风险展示：严重程度标签、类别、文件路径与行号、脱敏代码片段、修复建议
