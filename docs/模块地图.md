# 模块地图（改一块会影响哪儿）

| 模块 | 职责 | 依赖方 | 被依赖方 |
| :--- | :--- | :--- | :--- |
| `app/models.py` | 请求/响应 Pydantic 模型定义 | `pydantic` | 所有后端模块、前端字段解析 |
| `app/git_fetcher.py` | 校验 Git URL、浅克隆、读取 `HEAD` SHA 与分支 | 系统 `git` 命令 | `app/main.py` |
| `app/scanner.py` | 遍历仓库文件、执行四大维度扫描与密钥脱敏 | `app/models.py` | `app/main.py`、`tests/test_scanner.py` |
| `app/scorer.py` | 根据扫描结果计算 0-100 评分、等级与扣分明细 | `app/models.py` | `app/main.py`、`tests/test_scanner.py` |
| `app/ai_advisor.py` | 调用 LLM 生成接入建议，无 Key 或失败时规则兜底 | `httpx`、`app/models.py` | `app/main.py` |
| `app/main.py` | FastAPI 路由注册、异常映射、静态页托管 | 以上全部后端模块 | `app/static/index.html`、`tests/test_api.py` |
| `app/static/index.html` | 用户交互界面与 Chart.js 可视化渲染 | `app/main.py` (`/api/scan`) | 最终用户浏览器 |
